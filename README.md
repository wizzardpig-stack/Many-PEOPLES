# MANY PEOPLES

An interactive browser-based social systems simulation and visual experience built as a self-contained web prototype.

## Live build

https://wizzardpig-stack.github.io/Many-PEOPLES/

The stable root URL uses a lightweight `index.html` loader. The canonical V3.1 application remains stored under its versioned filename so large-file renames do not risk corrupting the build.

## What it demonstrates

- Large-scale single-file web application architecture
- Interactive simulation and visual storytelling
- Responsive browser UI and mobile adaptation
- State-driven JavaScript interactions
- Performance-oriented iteration on a visually dense experience
- Rapid product prototyping from concept through working public build

## Build

- HTML5
- CSS3
- JavaScript
- Browser-native rendering and interaction APIs
- No build step required

## Source of truth

Current canonical build: **MANY PEOPLES V3.1**

The versioned HTML file is the application source. `index.html` is intentionally only the stable public entry point.

## Development approach

Built through an AI-assisted development workflow with hands-on product direction, interaction design, testing, debugging, visual iteration, and release decisions. AI tools accelerate implementation while product architecture, requirements, evaluation, and final direction remain human-led.
